# Design

## Context

- 页面现状：`web/src/pages/SecurityPage.tsx`，四个文字段落 + 一个清单；E2E `security.spec.ts` 用 `data-testid`（`security-page`、`server-visible-list`、`web-e2ee-limits`、`lost-keys`、`recovery-advice`）与关键短语断言内容。
- `client-encryption` 规格要求页面列出：账号邮箱、文件夹树结构、密文大小与块数、创建/修改/删除时间、访问时间与 IP；并说明 Web 版依赖服务端下发的前端代码未被篡改。
- 视觉与动效遵循 `redesign-web-ui` 的 D2 令牌与 D10 动效规范（Dropbox 风格、克制、只用 CSS、尊重 reduced motion）。

## Goals / Non-Goals

**Goals：** 30 秒内看懂“我们看不到你的文件、你必须保管好恢复密钥”；首屏以图为主；默认可见文字 ≤ 350 个汉字；完整说明不丢失。

**Non-Goals：** 改变加密行为或对外承诺的内容；多语言；视频或外部图片资源。

## Decisions

### D1 页面结构（从上到下）

1. **首屏原理图**（`<figure>` + 内联 SVG，`role="img"` + 完整 `aria-label`）：
   左侧“你的浏览器”（笔记本图标，旁边一把钥匙“钥匙只在这里”）→ 文件图标进入、锁扣合上变成上锁的盒子 → 盒子沿虚线移动到右侧“服务器 / 阿里云 OSS”（云+机柜图标），那里堆放着几个上锁的盒子，旁边标注“只存锁着的盒子”。
   动画循环约 6 秒：文件出现 → 上锁（缩放+锁扣旋转）→ 移动 → 落入堆中；`prefers-reduced-motion` 时直接显示终态静帧。
   图下方一句话结论（H1 下的副标题）：“文件在你的浏览器里加密后才上传，我们和云厂商都打不开。”
2. **能看到 / 看不到**：两列卡片。
   - 左“服务器能看到”（灰色眼睛图标，`data-testid="server-visible-list"`）：账号邮箱；文件夹树结构（看不到名称）；密文大小与块数；创建、修改、删除时间；访问时间与 IP 地址。
   - 右“服务器看不到”（蓝色锁图标）：文件内容；文件名与类型；原始修改时间；你的密码；主密钥与恢复密钥。
   - 两列下方一行小字：“服务端不会收到明文文件内容、文件名、密码或任何密钥。”
3. **需要知道的局限**（`data-testid="web-e2ee-limits"`）：三张横排小卡（移动端纵排），每张：图标 + 标题 + 1–2 句。
   - 网页代码由服务端下发：“如果服务器被攻破，理论上可以下发窃取密码的代码，浏览器无法从数学上完全排除。我们用严格 CSP 和可复现构建降低风险。”
   - 你的设备也要安全：“恶意扩展、键盘记录器同样能读到你输入的密码。”
   - 更安全的选择：“将来会提供桌面客户端或浏览器扩展，可校验客户端代码。”
4. **忘记密码怎么办**（`data-testid="lost-keys"`）：三格对照，每格上方是两把钥匙图标（密码钥匙、恢复密钥），丢失的那把显示为虚线轮廓 + 斜杠；下方结果徽标与一句话：
   - 忘了密码、恢复密钥还在 → 绿色“可以恢复”：“用恢复密钥重置密码。”
   - 密码记得、恢复密钥丢了 → 黄色“尽快补救”：“登录后在设置里重新生成恢复密钥。”
   - 两把都丢了 → 红色“永久无法解密”：“服务器没有你的钥匙，任何人（包括我们）都无法恢复。”
   悬停/聚焦某格时该格轻微上浮（D10 fast）。
5. **保管恢复密钥**（`data-testid="recovery-advice"`）：两列图标清单，6 条短句：
   抄在纸上，不要只截图；至少准备两份，分开存放；可以存进密码管理器，但别和密码放在一起；不发给任何人，我们永远不会向你索要；怀疑泄露？立即轮换恢复密钥；每半年检查一次还能不能读出来。
6. **详细说明**：`<details>`（默认收起，摘要“查看完整说明”），内含当前页面的完整原文（保留全部信息，便于较真的用户与审计）。展开/收起有高度过渡（D10 base）。

### D2 插图实现

- 所有插图为 React 组件内的内联 SVG（`web/src/security/illustrations/`），颜色用 D2 令牌（`currentColor` + Tailwind 文本色类），线宽与 lucide 一致（1.75）。
- 动画只用 CSS `@keyframes`（transform / opacity / stroke-dashoffset），定义在组件旁的 CSS 模块或 `index.css` 的 `@layer components`；不使用 JS 驱动动画、不使用 SMIL `<animate>`（部分浏览器在 CSP 与 reduced motion 下行为不一致）。
- 区块进入视口时淡入上移（IntersectionObserver 只切换 class；不支持时直接显示）。reduced motion 下全部关闭。
- 不加载任何外部字体、图片或脚本。

### D3 文案

- 默认可见文字（不含“详细说明”）≤ 350 个汉字；每条要点不超过 20 个字（局限卡片正文除外，≤ 50 字）。
- 必须保留 E2E 与 `client-encryption` 规格要求的关键短语（见 tasks 3.1）。

## Risks / Trade-offs

- **信息被“简化”成不准确** → 原文完整保留在“详细说明”；可见要点逐条对应原文，审查时对照。
- **动画分散注意力** → 只有首屏一处循环动画，且尊重 reduced motion；其余为一次性进入动画。

## Migration Plan

纯前端，随下次部署上线。
