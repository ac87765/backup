# Spec Delta

## Purpose

把“安全与隐私”页面从长段落说明改为以图示与短句为主的可视化说明，同时保留完整原文，确保用户能在短时间内理解加密边界、局限与恢复密钥的重要性。

## ADDED Requirements

### Requirement: 安全与隐私页可视化说明
“安全与隐私”页面 SHALL 以图示为主呈现：首屏为说明“文件在浏览器加密、服务器只保存密文、钥匙只在用户手中”的原理图；“服务器能看到 / 看不到”以两列图标清单呈现；Web 版局限以三张卡片呈现；丢失密码与恢复密钥的三种后果以可视化对照呈现；恢复密钥保管建议以图标清单呈现。默认可见文字 MUST NOT 超过 350 个汉字；完整原文 MUST 保留在默认收起的“详细说明”中。页面 MUST 继续包含 `client-encryption` 规格要求的服务端可见信息清单与“依赖服务端下发代码”的说明。

#### Scenario: 一屏看懂原理
- **WHEN** 用户打开“安全与隐私”页面
- **THEN** 首屏显示原理图（带可访问的文字描述）与一句话结论，无需滚动即可看到

#### Scenario: 丢失两把钥匙的后果
- **WHEN** 用户查看“忘记密码怎么办”区域
- **THEN** 能看到三种情况的对照，其中“密码和恢复密钥都丢失”明确标为“永久无法解密”

#### Scenario: 完整说明可展开
- **WHEN** 用户点击“查看完整说明”
- **THEN** 展开显示原有的完整文字说明；再次点击收起

#### Scenario: 减少动态效果
- **WHEN** 系统开启“减少动态效果”时打开页面
- **THEN** 原理图直接显示静止的最终画面，页面上没有运行中的动画

#### Scenario: 严格 CSP 下正常显示
- **WHEN** 在真实服务端的严格 CSP 下打开页面
- **THEN** 所有插图正常显示，控制台没有 CSP 违规，页面不请求任何外部资源
