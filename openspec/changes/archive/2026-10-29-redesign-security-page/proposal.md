# Proposal

## Why

“安全与隐私”页面目前是几大段说明文字（约 1500 字），内容准确但很少有人读完。用户反馈“文字太长，没耐心看”。这个页面承担着向用户解释端对端加密边界、局限与恢复密钥重要性的职责——没人看等于没说。需要把它改成“一眼看懂”的可视化页面：图示与轻动画讲清楚原理，要点浓缩为短句，完整说明折叠起来按需展开。

## What Changes

- 首屏用一张带轻动画的原理图（文件在浏览器里上锁 → 只有锁着的盒子被送到服务器 → 钥匙始终留在用户这边）配一句话结论，替代开头的段落。
- “我们能看到 / 看不到”改为左右两列的图标清单，每项一行短语。
- Web 版局限改为三张小卡片（代码由服务端下发、设备安全、将来的桌面客户端），每张 1–2 句。
- “忘记密码怎么办”改为三种情况的可视化对照（两把钥匙的状态 → 结果），一眼看出“两把都丢 = 永久无法解密”。
- 恢复密钥保管建议改为带图标的清单（6 条短句）。
- 原有完整文字保留在页面底部可折叠的“详细说明”中。
- 全部图示为内联 SVG + CSS 动画，遵守严格 CSP，尊重“减少动态效果”；不引入新依赖。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `web-ui`：新增“安全与隐私页可视化说明”需求（页面结构与呈现方式）。`client-encryption` 的“服务端可见信息边界”需求内容不变，页面仍须列出其要求的全部信息。

## Impact

- 代码：`web/src/pages/SecurityPage.tsx` 重写，新增 `web/src/security/` 下的插图组件；`web/e2e/security.spec.ts` 扩展。
- 无服务端、加密、依赖变更。
