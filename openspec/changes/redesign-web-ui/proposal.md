# Proposal

## Why

MVP 的功能已经在真实环境（阿里云 ECS + OSS）跑通，但 Web 界面是开发期的“表单堆叠”风格：所有页面都是居中卡片，文件页把操作按钮平铺在每一行，没有侧边栏、没有图标、没有视图切换，传输队列和回收站挤在同一页。用户反馈“能用但很简陋”，希望达到 Dropbox / 百度网盘这类成熟网盘产品的观感与易用性。

这是纯前端的体验改造：不需要新的交互范式，直接沿用主流网盘已经被大量用户熟悉的布局与操作习惯。

## What Changes

- 新增 `web-ui` 能力规格，定义应用外壳、文件浏览、上传与传输、对话框与反馈、账号菜单、认证页面、响应式与可访问性的界面契约。
- 引入统一的设计令牌（颜色、圆角、阴影、间距、字号）与一组基础组件（按钮、输入框、对话框、下拉菜单、提示、空状态、进度条、文件图标）。
- 登录后采用“左侧导航 + 顶部栏 + 主内容区”的网盘布局：侧边栏含“全部文件 / 回收站 / 安全与隐私”与存储用量条；顶部栏含面包屑、当前文件夹内筛选、视图切换与账号菜单。
- 文件页改为列表视图（名称 / 修改时间 / 大小列，可排序，悬停显示快捷操作，“更多”菜单与右键菜单承载其余操作）与网格视图（大图标卡片），按文件类型显示图标；空文件夹显示引导。
- 主按钮“上传”带下拉（上传文件 / 新建文件夹）；整页拖拽上传显示覆盖层提示。
- 传输队列改为右下角可折叠的浮动面板，显示总体进度与逐项状态，保留暂停 / 继续 / 重试 / 取消。
- 回收站成为独立视图（侧边栏进入），版本历史、重命名、移动、新建文件夹统一为模态对话框；操作结果用轻提示（toast）反馈。
- 认证类页面（登录、注册、验证、解锁、重置）改为品牌化的居中布局；账号设置类页面（修改密码、恢复密钥轮换、登录设备）并入外壳内的“账号设置”区。
- 移动端（< 768px）侧边栏收为抽屉，列表自适应。
- 不改变任何加密、API、Worker 边界与 CSP；不引入外部字体、CDN 或运行时远程资源。

## Capabilities

### New Capabilities

- `web-ui`：Web 客户端的界面布局、组件与交互契约。

### Modified Capabilities

无。现有 `file-management`、`file-transfer`、`user-accounts`、`client-encryption` 的行为契约保持不变，本变更只改变其呈现方式。

## Impact

- 代码：`web/src/` 下的页面与组件大规模重写；新增 `web/src/ui/`（设计令牌与基础组件）；`FilesPage.tsx` 拆分为多个组件。
- 依赖：新增 `lucide-react`（MIT，内联 SVG 图标，按需打包，不访问网络）。不引入其他 UI 框架。
- 测试：E2E 的选择器可能需要随新导航调整，但每个现有断言所验证的行为必须保留；新增界面相关组件测试与截图脚本。
- 部署：仅前端静态资源变化；服务端二进制、数据库、OSS 配置不变。
