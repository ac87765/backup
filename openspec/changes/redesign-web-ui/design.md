# Design

## Context

- 前端：React 19 + React Router 7 + Tailwind CSS v4 + Vite；加密与网络请求在 Web Worker 中（Comlink），主线程只做界面。
- 严格 CSP：`default-src 'self'`，`connect-src` 只允许自身与对象存储 origin；不允许内联脚本、外部字体或 CDN。
- E2E（Playwright）通过 `data-testid` 与可访问名称（`aria-label`、按钮文字、标题）定位元素，共 6 个 spec、约 180 处定位。
- 目标用户是少量个人用户，使用中文界面，桌面浏览器为主，也会用手机查看。
- 参考对象：Dropbox Web、百度网盘 Web 版。只借鉴通用布局与交互模式，不复制其商标、Logo、插画或专有图形。

## Goals / Non-Goals

**Goals：**
- 观感接近成熟网盘：大量留白、清晰层级、统一图标与配色、克制的阴影与圆角。
- 高频操作一步可达（上传、新建文件夹、打开、下载），低频操作收进“更多”菜单。
- 现有全部功能在新界面中都有入口，行为不变。
- 键盘可用、读屏可用、移动端可用。

**Non-Goals：**
- 暗色模式、主题切换、多语言。
- 跨文件夹搜索（文件名是密文，服务端无法搜索；只做当前文件夹内的本地筛选）。
- 多选与批量操作、文件预览/缩略图、分享链接（后续 change 再议）。
- 任何 API、Worker 协议、加密或服务端改动。

## Decisions

### D1 布局：左侧导航 + 顶部栏 + 主内容区

登录后的所有页面共用 `AppShell`：

```
┌──────────────┬──────────────────────────────────────────────┐
│  品牌名       │  面包屑 › 路径          [筛选] [列表|网格] (头像)│
│              ├──────────────────────────────────────────────┤
│ [+ 上传 ▾]    │  名称 ▲            修改时间        大小       │
│              │  📁 照片             2026-10-20 14:03   —      │
│ 📁 全部文件   │  📄 合同.pdf          2026-10-21 09:12   1.2 MB │
│ 🗑 回收站     │  ...                                          │
│ 🛡 安全与隐私 │                                              │
│              │                                              │
│ ─────────    │                                     ┌────────┐│
│ 已用 1.2 GB   │                                     │传输面板 ││
│ ▓▓▓░░░ /10 GB │                                     └────────┘│
└──────────────┴──────────────────────────────────────────────┘
```

- 侧边栏宽 240px，白底，右侧 1px 分隔线；当前项浅蓝底 + 蓝色文字。
- 顶部栏高 64px；账号头像为邮箱首字母圆形徽标，点击展开账号菜单。
- `/` 重定向到 `/files`（原 HomePage 的信息并入账号菜单与账号设置页）。
- 回收站路由 `/trash`；账号设置 `/settings`（含修改密码、恢复密钥、登录设备三个分区，原路由保留并重定向到对应分区，避免书签与邮件链接失效）。

### D2 设计令牌（Tailwind v4 `@theme`）

在 `web/src/index.css` 中用 `@theme` 定义，组件只能使用令牌，不写零散色值：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-brand-600` | `#0061fe` | 主按钮、链接、选中态 |
| `--color-brand-50` | `#eef4ff` | 选中行、导航当前项背景 |
| `--color-ink-900` | `#1e1919` | 主文字 |
| `--color-ink-600` | `#52525b` | 次要文字 |
| `--color-line` | `#e7e5e4` | 分隔线、边框 |
| `--color-canvas` | `#f7f7f6` | 外壳背景 |
| `--color-danger-600` | `#dc2626` | 危险操作 |
| `--radius-card` | `12px` | 卡片、对话框 |
| `--radius-control` | `8px` | 按钮、输入框 |
| `--shadow-pop` | `0 8px 24px rgb(0 0 0 / 0.12)` | 菜单、浮层 |

字体使用系统字体栈（`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`），不加载 Web 字体。

### D3 基础组件放在 `web/src/ui/`，不引入 UI 框架

`Button`（primary / secondary / ghost / danger，sm / md）、`IconButton`、`TextField`、`Dialog`（基于原生 `<dialog>` + `showModal()`，自带焦点陷阱与 Esc 关闭）、`Menu`（下拉与右键菜单共用，方向键导航、Esc 关闭、点击外部关闭）、`Toast`（右上角，3 秒自动消失，可读屏播报 `role="status"`）、`EmptyState`、`ProgressBar`、`FileIcon`（按扩展名映射图标与颜色）、`Spinner`。

理由：组件数量有限，自写可完全控制 CSP 与包体；Radix / MUI 等框架体积与样式体系与 Tailwind 冲突，不值得。

### D4 图标：`lucide-react`

MIT 许可，ESM 按需导入（只打包用到的图标），输出内联 SVG，不触网，不违反 CSP。文件类型映射：文件夹、图片、视频、音频、PDF、文档、表格、演示、压缩包、代码、文本、其他。

### D5 文件页组件拆分

`FilesPage.tsx`（1238 行）拆分为：`FileBrowser`（数据加载与状态）、`FileToolbar`、`FileList`（列表视图，沿用 `VirtualList` 虚拟滚动）、`FileGrid`（网格视图）、`FileRowActions`（悬停操作 + 更多菜单）、`TrashView`、`dialogs/`（新建、重命名、移动、版本历史、确认删除）、`TransferPanel`。
数据加载、解密、Worker 调用的逻辑原样迁移，不改变调用顺序与错误处理。

### D6 列表交互

- 单击行选中（浅蓝底），双击或单击名称打开文件夹 / 下载文件。
- 行悬停时在右侧显示快捷按钮：下载、更多（⋯）。“更多”菜单：重命名、移动到…、版本历史、上传新版本、删除。右键行弹出同一菜单。
- 列头可点击排序（名称 / 修改时间 / 大小），文件夹始终排在文件前；排序与视图模式保存在 `localStorage`（只存这两个界面偏好，不存任何文件信息）。
- 当前文件夹筛选：顶部输入框，本地按解密后的名称过滤。

### D7 传输面板

右下角浮动卡片（宽 360px），标题行显示“正在上传 3 项 · 45%”与折叠/关闭按钮；展开后列出每一项（文件图标、名称、进度条、速率/剩余或状态、操作按钮）。全部完成后标题变为“上传完成”，可一键清除已完成项。保留现有 `transfer-*` 测试钩子与状态属性。

### D8 测试钩子兼容策略

- 所有现有 `data-testid` 保留在语义等价的新元素上（例如 `file-row` 仍标在每一行；`open-trash` 标在侧边栏“回收站”入口）。
- 操作按钮的可访问名称保持不变（如 `下载 {name}`、`删除 {name}`、`版本历史 {name}`），即使它们移入“更多”菜单——菜单项使用相同的 `aria-label`。
- 允许因导航结构变化而更新 E2E 的步骤（例如先打开“更多”菜单再点删除，或通过账号菜单进入修改密码），但每个断言验证的行为 MUST 保留，不得删除断言或放宽条件。
- `home-email` 等原主页钩子迁到账号菜单 / 账号设置中显示邮箱的元素上。

### D9 截图审查

新增 `web/e2e/screenshots.spec.ts`（仅在 `E2E_SCREENSHOTS=1` 时运行），在 1440×900 与 390×844 两种视口下对登录、注册、文件列表（含数据）、网格视图、空文件夹、回收站、传输面板、版本历史对话框、账号设置页截图，输出到 `web/e2e-tmp/screenshots/`（已 gitignore）。供审查者人工比对，不做像素断言（跨平台字体渲染差异会导致误报）。

## Risks / Trade-offs

- **E2E 大面积改动可能掩盖回归** → D8 约束：只允许改定位步骤，不允许改断言；审查时逐个 diff E2E 文件。
- **拆分 FilesPage 引入逻辑回归** → 数据与 Worker 调用逻辑整体搬迁，单测与 E2E 全量覆盖上传、下载、版本、回收站、移动、重命名。
- **右键菜单与浏览器默认行为冲突** → 只在文件行上拦截 `contextmenu`，其他区域保持默认。
- **localStorage 存界面偏好** → 只存 `viewMode` 与 `sort` 两个非敏感值，符合“密钥不落地”规则。
- **新依赖 `lucide-react`** → 体积可控（按需导入），许可宽松；若审查发现打包体积增长超过 60 KB（gzip），改为只复制所需 SVG。

## Migration Plan

纯前端发布：合并后构建新镜像，在服务器上替换 `server` 容器即可；无数据迁移。旧路由通过重定向保持可用。回滚即切回上一镜像标签。
